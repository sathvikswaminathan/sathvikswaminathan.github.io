I'm Sathvik Swaminathan, a Silicon Design Engineer at AMD. Before that I was a Research Scientist at Intel Labs.

My background is on the CPU side — performance analysis, and memory management in tiered memory systems. That's the lens I bring to everything here: someone used to reasoning about cache hierarchies, page placement, and where the cycles actually go on a CPU.

Now I'm learning GPUs, and this site is where I document that. The parts that transfer, the parts that don't, and the parts where my CPU intuition turned out to be actively misleading.

So the posts are written for the person I was when I started: comfortable with computer architecture, new to the GPU execution model. They tend to work from first principles — why the hardware is shaped the way it is — rather than cataloguing API calls, because that's the explanation I kept wishing someone had written down.

You can find my code on [GitHub](https://github.com/sathvikswaminathan).
